# Отзывы для oldartcollection.com

Каждые 4 часа собирает рейтинг и отзывы с Авито (официальный API), добавляет Мешок и Яндекс Карты
и публикует `reviews.json` (~5 КБ):

https://dinyarik.github.io/oldart-reviews/reviews.json

Сайт читает только этот файл. Ключей на сайте нет.

- Рейтинг и отзывы Мешка — вручную, в `collect.py` (блок `MESHOK` / `MESHOK_REVIEWS`): API Мешка их не отдаёт.
- Запустить обновление вручную: вкладка **Actions** → «Обновить отзывы» → **Run workflow**.
- `widget.js` — код блока отзывов и строки рейтинга для Тильды (справочно; на сайте он вставлен в HTML-блоки).
